# projeto-biblico-revisao

Site estático de revisão de conteúdo do Projeto Bíblico (GitHub Pages).
Protegido por senha — o conteúdo (`devocionais.enc`) é cifrado (AES-GCM); a senha
só é usada no navegador para descriptografar.

Fonte e build: repo `projeto-biblico-pipeline`, pasta `review-site/`.
Este repo recebe só os arquivos publicados (index.html, config.js, devocionais.enc).
